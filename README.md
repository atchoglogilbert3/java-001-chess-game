# Java Project Roadmap

A cumulative, project-based Java learning roadmap. Each repository introduces new programming chapters while reusing and combining concepts from previous projects.

| **#** | **Repository** | **Level** | **New programming chapters** |
|---|---|---|---|
| 000 | `java-000-number-guessing-game` | Beginner | Programming Basics; Data Types and Expressions; Conditional Statements; Loops; Methods; Arrays; Console Input and Output |
| 001 | `java-001-chess-game` | Beginner+ | Object-Oriented Programming; Classes and Objects; Constructors; Encapsulation; Inheritance; Polymorphism; Interfaces |
| 002 | `java-002-movie-recommendation-system` | Intermediate | Collections Framework; Generics; Enumerations; Records; Functional Interfaces; Lambda Expressions; Streams API |
| 003 | `java-003-hotel-reservation-system` | Intermediate+ | Exception Handling; Data Validation; Domain Modeling; Design Patterns; State Management; Date and Time API |
| 004 | `java-004-document-processor` | Advanced | File Handling; Java NIO; Parsing; Serialization; Resource Management; Regular Expressions |
| 005 | `java-005-search-engine` | Advanced+ | Algorithms and Data Structures; Multithreading; Concurrency; Parallel Programming; Asynchronous Programming; Performance Optimization |
| 006 | `java-006-chat-application` | More advanced | Modular Programming; Networking; HTTP Clients; WebSockets; Java Native Interface (JNI); Dependency Injection |
| 007 | `java-007-ecommerce-platform` | Expert | Application Architecture; Database Programming (JDBC); Persistence (JPA); REST APIs; Testing; Build and Dependency Management; Application Packaging and Deployment |

## Learning Structure

**Project → Chapters → Topics → Coding Assignments**

Each coding assignment specifies the programming concepts introduced, a concrete feature to implement, code snippets, and an explanation.

## Progression

Java Fundamentals → OOP → Functional Java → Application Design → File Processing → Concurrency → Networking → Enterprise Development.
